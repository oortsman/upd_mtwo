## instructions

download "latest release" ^

!!! backup your mafia 2 saves (the mod won't do it for you)

unzip the mod, run MAFIAMOD

select language

find game (if it's in C:/, "copy game" or "replace existing install")

choose player name

continue, wait for the mod to finish editing game files

decide whether you want to download 2 new radio stations (takes a little while to graft them onto your game)
